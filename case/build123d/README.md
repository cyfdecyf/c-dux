# C. Dux 垂直站立底座

`stand.py` 是垂直站立底座的 Python/build123d 实现。要点:

- 默认导出 **STL**(切片用),`--step` 加导 STEP —— STEP 是嘉立创等
  代打服务的首选格式
  (精确 B-rep,非网格近似);
- B-rep 圆角:底座顶面周边 2 mm 圆角(OpenSCAD 做不到);
- **两件式**:底座与立板(背板+柱+靴座)拆成两个零件,榫键 + 2×M4 螺丝
  连接——底座只打印一次(完全对称,不分左右),试不同后仰角只换立板件
  (`--tilt`,当前默认 30°、配 `--set-angles -35`);
- **孔位/板框不手抄**:每次运行直接从 `pcb/v2.0/c-dux.kicad_pcb` 解析
  4 个 M4 孔坐标与板框尺寸,并与已验证的孔位表断言(±0.05 mm)。
  PCB 改版后若不一致,脚本拒绝出图——底座与板子不会悄悄失配。

## 设计:垂直(dodo 式)站姿

面向**站立使用**:手臂自然垂下,手掌侧向,手指沿列方向卷曲按键。因此:

- **列竖直**:小指加高键(单键)朝下、三键拇指簇朝上(与 Dodo 等
  垂直键盘一致,孔位映射见下节);
- 后仰角 `tilt`(默认 30°;照片实测站立舒适姿约 20–30°,换角度只
  重打立板,见"两件式结构"一节);
- 旋钮(encoder)随拇指簇位于站姿上部、正对使用者,正好当音量键用;
- MCU/XIAO、JST、USB 出线都在背板中上部:USB 线从侧面引出,不碰
  背板和底座;
- 裸板使用:PCB 由 4 根柱子架在背板前,`post_h`(默认 3 mm)保证
  背面的轴座/焊点/连接件不碰到背板;键帽朝向使用者一侧;
- 抗后倾不靠配重:底座向后仰侧延伸(`base_rear` 100 mm)拉长力臂
  (见"键盘离台高度与底座尺寸"一节),默认无硬币槽等配重件。

## 安装朝向(单键区朝下,拇指区朝上)

键盘装上底座的方向:**小指加高键(单键)朝下、三键拇指簇朝上**。
孔位映射据此翻转(`u = Y_max − Y_kicad`,`v = X_kicad − X_min`),因此
MCU/XIAO、JST、USB 出线位于背板中上部。

## 安装孔位与背板高度(单组)

背板上只有 **1 组 M4 柱位**:同一 4 孔图案绕图案质心旋转一个角度
(默认 -35°,`--set-angles` 可改,负值 = 反方向倾斜)——这个平面内
旋转角就是 home row 的倾斜度,手腕前倾越多取越大角度;换角度需
重打立板。

- 柱位由求解器自动排布:横向居中,并求最小抬升,保证 **PCB 最低材料点
  (按 Edge.Cuts 实际板框逐角度采样,非包围盒角点——右下角 bbox 角处
  没有板料)距底座顶面 ≥2 mm**;整组柱位再沿背板整体下移
  `keyboard_drop` 20 mm(用户要求“键盘下移 3cm”;先试过 28,但最低沉孔
  被靴座埋住无法放螺母,回收到 20 让沉孔口完全露出靴座顶面,见“键盘离台
  高度与底座尺寸”一节);
- **背板高度按需取**:立板只需在竖直方向上覆盖"螺丝孔 → 桌面"的
  投影距离并留余量(`top_rim`,5 mm,压在最高柱顶之上)——PCB 高于
  最高螺孔的部分悬出于背板之外,由 4 根柱悬臂承托;
- **背板轮廓收腰**:PCB 悬在柱前端、从不接触板面,所以肋带以上的
  轮廓自动收缩为“柱位包络的凸包”——只需包住 4 根柱(柱心外扩
  10 mm)和柱间腹板,底部保留收窄的底带(每侧按最外柱/肋的实际
  包络取宽、偶数 mm 取整,并比底座窄 2 mm 避开底座顶面圆角;
  靴座、榫槽、螺
  母座、肋的立足都在这里;柱位外摆越出底带时,只保留带圆角过渡
  的局部凸台,如 30°/−35° 姿态)。收腰不碰任何装配特征,20° 立板
  省 ~16 cm³(PA12 约 −16 g);
- **腹板减重孔:已移除**(曾自动布 Ø52 孔,省料 ~12.7 cm³):站立
  打印姿态下孔顶近乎水平,等于 ~52 mm 的桥接,拖累打印成功率,故
  整体删除;省料仍由轮廓收腰承担;
- 加强肋(厚 12 mm,沿背面升高 70 mm,x 位置由柱位布局自动避让求解,
  同时避让榫键与螺钉);当前 30°/−35° 布局下移后柱位整体沉入肋带,
  左侧候选全部撞上接合螺钉避让区,只放得下 1 根(右侧,脚本会打
  warning——布局拥挤的正常结果,见下);

## 环境(uv)

```sh
cd case/build123d
uv sync          # 创建 .venv,按 uv.lock 安装(build123d 0.11.1)
```

## 用法

```sh
uv run stand.py --part base                # 共享底座(打印一次,不分左右)
uv run stand.py --part upright             # 左立板,30° 后仰
uv run stand.py --side right --part upright
uv run stand.py --part upright --tilt 10,15,20,25,30   # 一批角度的立板
uv run stand.py --part upright --flange 8   # 立板加可掰法兰(黏板保险)
uv run stand.py --part full                # 装配预览(两件布尔并,左半)
uv run stand.py --part joint               # 配合试块(先打这个!)
uv run stand.py --part fit                 # 平板验证件(旧,柱位实配用)
uv run stand.py --set-angles -35           # 安装组平面内旋转角(默认 -35)
```

输出到 `out/`:`stand_base.*`(底座,不分左右)、
`stand_<side>_upright_t<角度>.*`(立板)、`stand_<side>_full_t<角度>.*`
(装配预览)、`joint_coupon_base.*` / `joint_coupon_boot.*`(配合
试块,两个独立文件,各自平放即打印姿态)。默认只导出 STL(切片用),加
`--step` 同时导出 STEP——代打服务的首选格式(精确 B-rep,非网格近似)。
终端打印包围盒、体积与估重(实心体积;FDM 有填充时实际更轻)。默认行为 =
**只导出文件**;想实时预览加 `--show`(推送 OCP CAD Viewer、不导出文件)。
查看器没开或半开只打印一行提示,文件产出不依赖查看器。

| 参数 | 默认 | 说明 |
|---|---|---|
| `--part` | `full` | `base` 共享底座 / `upright` 立板 / `full` 装配预览 / `joint` 配合试块 / `fit` 平板验证件 |
| `--tilt` | `30` | 立板/装配预览的后仰角(度),逗号分隔可批量出图 |
| `--side` | `left` | 左/右半(底座对称,忽略此参数) |
| `--set-angles` | `-35` | 安装组的平面内旋转角(度) |
| `--post-h` | 3 | 柱高 = PCB 与背板间隙 |
| `--attach` | `nut` | `nut` 背面螺母沉孔 / `tap` 自攻(仅 PCB 柱位) |
| `--flange` | `0` | 靴座四周可掰法兰,值 = 外伸宽度(mm);底板黏性不足的保险,打印后掰掉 |
| `--show` | — | 只推送到 OCP CAD Viewer 预览,不导出文件 |
| `--pcb` | `pcb/v2.0/c-dux.kicad_pcb` | 孔位与板框来源 |
| `--out` | `out/` | 输出目录 |

其余几何参数(背板/底座/筋条/胶垫/连接件尺寸)是 `stand.py` 顶部的
模块常量,改源码即可调整。交互预览:VS Code 装
**OCP CAD Viewer** 插件,面板 Open Viewer 后运行本脚本即实时显示
(推送走 dev 依赖 `ocp-vscode`,每次推送自动取景);没开查看器时,
把 `out/*.step` 拖进任何 CAD 查看器也可以。

## 两件式结构:共享底座 + 按角度换装立板

底座(132.5 × 130 × 6 mm,**已按此宽度打印**,是两件宽度的基准;
立板每侧内缩 2 mm,避开底座顶面的 2 mm 圆角;
厚 6 与前裙边 `base_front` 30 是省料刀——前向只有拉拽/碰撞的偶发
载荷,打字主工况的后倾力臂全在 `base_rear` 100 里;胶垫随外轮廓外移,
补回倾覆支点力臂)与立板(背板 + 4 柱 + 靴座)拆成两个零件,目的是
**底座只打一次**,试不同后仰角只重打立板:

- 接合面是水平座面(z = 6 mm),所有连接特征都用世界坐标定义、与倾角
  无关——同一底座配任意角度的立板,而且完全对称、不分左右;
- **连接 = 2 榫键 + 2×M4**:底座顶面两根 30 × 8 × 3.2 mm 榫键(x = ±12,
  顶缘 0.5 mm 倒角)抗剪、定位;立板靴座底开 0.4 mm 间隙的榫槽;
  2 颗 M4×12 内六角**从底座底面的沉头孔(x = ±58)向上拧**,穿过底座
  与靴座,拧进靴座顶部的螺母座(7.4 mm 跨面 × 3.4 mm 深,开口带
  6.9 mm 收口唇,螺母压入后常驻立板,不随拆卸丢失)。为什么从下面拧:
  立板后仰后背板悬在靴座顶上方 ~48 mm,从上往下拧螺丝刀没有空间;
  底面完全敞开,而且螺丝长一点也不占地方;
- 承载分工:敲击压力由座面大平面承担,水平剪力由榫键承担,前撬与夹紧
  由 2 颗 M4 承担。键顶/槽顶分别比座面高 3.2 / 3.6 mm,立板承压全
  落在座面上,不搁在键上;
- **换角度 = 拧 2 颗螺丝**:松螺丝 → 取下立板 → 换角度件 → 紧回
  (螺母常驻靴座;每块立板可自配一对,换装时不倒腾螺母)。装配姿势:
  螺母先压入靴座、立板落到榫键上,然后把组装体侧翻或垫高,从底面
  拧 2 颗螺丝——不能整体翻平,立板会顶桌面;
- BOM 每侧新增:**2 × M4×12 内六角螺钉**(其余 M4 紧固件不变;螺钉
  尖端会高出靴座面 ~2 mm,处在背板后方的敞空处,无碍);
- 公差按下方"嘉立创代打"的基准取 0.4 mm;先打 `--part joint` 配合试块
  (两小块,几分钟),实测榫键推入手感与螺母收口唇,再下整件订单。

## 结构强化(垂直敲击工况)

垂直打字时,每次敲击都经背板传入"底座×立板"交界处,是反复冲击弯矩。
拆成两件后交界强度不再靠埋入,以下强化全部保持免支撑打印:

- **靴座**(与背板等宽,高 8 mm,进深自动推导):立板底部的"脚",在
  座面上满接触承压,交界不再是一条内角线;进深在 `__init__` 里按三个
  下限取最大——螺母座后壁 ≥1.5 mm、肋底 6 mm 后壁、打印质心投影距
  后沿 ≥8 mm(先用下限建临时件实测质心,不足则自动再后伸,偶数 mm
  取整;t30/−35 实例 34 mm),打印件始终可自由站立——原先手工取 34
  (首版 26 深,质心 y≈29.4 落在接触区外 3.7 mm 才后伸的);榫槽开在
  靴座底,螺母座承力底加厚到 3.6 mm(夹紧力长期压在这层塑料上,防蠕
  变松弛);
- **托肩楔**(深 12 mm,高度按布局自动封顶 2–10 mm):靴座之上沿背面
  的缓坡,继续填交界内角;脊线不得顶到最低柱背面的螺母沉孔口
  (`_cap_haunch`,柱心后 6.5 mm 为界),下限 2 mm——再低就只是软化
  尖角的薄棱,承载由肋负责;图案下移 28 后 t30/−35 实例只剩 2 mm 棱;
  (首版 18 深、定高 10,随"底部收窄"一并收窄;它几乎全藏在靴座盒
  内,此项基本不改体积,改的是露出靴座台面的棱线);
- **加强肋**(厚 12 mm,沿背面升高 70 mm,x 位置由柱位布局自动
  避让求解,同时避让榫键与螺钉):抑制背板在肋间的弯曲;图案下移 28 后
  当前 30°/−35° 布局只剩右侧 1 根(左侧候选全部撞上接合螺钉避让区,
  脚本打 warning,布局拥挤的正常结果;肋底由 8×22 加宽到 12×20、
  高度 60→70 的历史不变:底深曾加深到 30,首版打印反馈偏臃肿后收窄
  回 20,省料主要在这里,强度靠 4 层壁);
- **2×M4 螺栓连接**:敲击把背板向前撬的受拉侧现在由螺栓拉住,而且
  可重新紧固——蠕变松弛后拧紧一圈即可,这是整体件做不到的可维护性。

原整体件的"埋入 4 mm"与"前侧内角 2.5 mm 圆角"随拆分取消:前侧受拉
内角属于装配体,单件上不存在;靴座提供的交界材料远多于埋入。

## 键盘离台高度与底座尺寸

![底座 front/rear/进深与抗倾力臂示意](../../images/stand-base-dimensions.png)
（由 `base_dims_diagram.py` 从 `stand.py` 常量自动生成，
`uv run base_dims_diagram.py` 重新出图；PNG 需要系统装 rsvg-convert）

键盘的最低点 = **Edge.Cuts 实际板框**旋转后的最低材料点:`parse_pcb`
把板框逐段 ~1 mm 采样,求解器逐安装角取旋转后的最小值(实测 19 颗键
的键帽都不超出板边,键帽不会比板边更低)。注意它不是包围盒角点:
t30/−35 姿态下虚拟角点 (u=112.5, v=0) 处没有板料,真实最低点在小指/
无名指列的板底边,比虚拟角点高 ~31 mm。高度约束仍是 **旋转后 PCB
最低材料点距底座顶面 ≥2 mm**,求解器求最小抬升;在此之上整组安装
图案再沿背板下移 `keyboard_drop 28`(用户实测"键盘下移 3cm"的需求,
收缩到 28 是为保住最低柱的喇叭口与背面螺母沉孔不越出板底缘)。下移
后背板底缘基本贴着键盘最低边(t30/−35:板缘比最低材料点低 ~1.8 mm,
最低材料点距底座顶面还余 ~0.9 mm,2 mm 余量线不再是最紧约束);底座
顶面高度由 `base_t 6` 控制,板底直接落在座面,交界强度交给
靴座+榫键+螺丝。底座各向:`base_front 30`(只防前向拉拽/碰撞,
前向载荷偶发且小)、`base_side 10`(横向 132.5 mm,已按此打印;
立板每侧内缩 2 mm,横向支撑靠胶垫跨距)、`base_rear 100`(键盘后仰侧加长,进深 130 mm,
拉长抗后倾力臂)。

抗后倾的支点是**胶垫接触线**而非板边:倾覆条件 `W·d ≥ F·h`,
d = 重心到后垫线的距离,`base_rear` 与胶垫外伸量(`pad_edge`)各自
1:1 贡献力臂;前/后垫线离板边只剩 `base_r + pad_edge` = 12 mm,
垫圈凹槽仍完整落在底面平面上。

## 打印建议

- **按建模姿态打印、无需支撑**:底座底面朝下——胶垫凹槽底被 1 mm
  减胶槽拆成座环与中心盘两个小桥接(首版整面平底实印下垂后改的),
  减胶槽顶是 1 mm 宽的小环桥、藏于垫下;螺丝沉孔台肩是 1.75 mm 宽
  的环形小桥接(实印验证);立板座面朝下——柱顶实心朝上、
  靴座螺母座开口朝上敞开,背面 PCB 螺母沉孔带收口唇斜朝下开
  (唇环 ~0.3 mm 宽,逐层审计无孤岛),靴座底机槽是贯穿窗口、无桥接;
- **孔内拉丝**:实印中沉头孔/通孔内壁下方会有少量拉丝——不影响
  螺丝沉头贴合(受力在孔顶台肩面)与装配,用小刀清理即可;预防靠
  干料、加大回抽,以及切片器的拉丝检测/防 oozing 选项;
- **立板下前缘 45° 倒角**(`lip_chamfer`):背板底缘面原本以
  (90°−tilt) 掠过床面,是打印时唯一真实悬浮的区域(逐层差分审计:
  759 层合计 ~3 cm² 悬空,集中在 z 7–8 mm 的靴座前唇);倒角后每层
  前移 ≤ 半根线宽,全件无悬浮;
- 0.2 mm 层高、3–4 层壁、10–15% gyroid 填充;PLA/PETG 均可(PETG 更
  耐蠕变),长期使用建议 PA12(见下节"嘉立创代打");
- 两件拆开后各自都放得进常见 220×220 成型尺寸打印机:底座
  132.5 × 130 × 6 mm,立板包围盒以脚本运行时的终端输出为准。

### 自打(以拓竹 H2C 为例)

- **材料选 PETG**(拓竹 PETG / PETG HF 均可):耐蠕变——长期反复
  敲击工况的关键指标;收缩小,0.4 mm 榫键间隙与螺母座公差按 FDM
  基准设计,尺寸稳。PLA 也可(最稳最快,但长期敲击会蠕变,夏天
  暴晒有软化风险);不推荐 ABS/ASA——收缩大且不均,0.4 mm 配合
  间隙的实际值不可控,榫键连接易松旷,132 mm 大平面底座还有翘曲
  风险;
- **材料干燥**:PETG 新开封可直接打,敞开放置较久或潮湿环境先
  65 °C 烘 6–8 h(打印机/料盒的干燥功能均可);
- **切片**:`out/*.stl` 直接导入 Bambu Studio(STEP 是代打格式,
  自打用不上);导入后**保持建模姿态**——关自动摆正与支撑;底板
  黏性不足时不加 brim,出图时改用 `--flange` 可掰法兰(打印后掰掉,
  不留在零件上,也不弄脏外观面);0.2 mm 层高、3–4 层壁、10–15%
  Gyroid 填充,顶/底层默认;

  尺寸 325 × 320 mm,两件可同板一次打完;
- **先打试件**:`--part joint` 验证榫键推入手感与螺母收口唇,流程
  见下方"嘉立创代打"一节。

## 装配

1. **立板装底座**:2 × M4×12 从底座底面沉头孔向上拧入靴座螺母座,
   换角度 = 拧 2 颗螺丝(流程与姿势见"两件式结构"一节);
2. **固定 PCB**:4 × M4×12 内六角螺钉——螺母先从背板**背面**压入
   六角沉孔(总深 4.6 mm:6.9 mm 收口唇 + 7.4 mm 螺母位,留 1.4 mm
   前壁;收口唇把螺母常驻在立板上,不随拆卸丢失)。当前下移 20 mm
   下 4 个沉孔口都在靴座顶面之上,直接敞开可及;若加大 `keyboard_drop`
   导致最低沉孔被靴座埋住,代码会自动在靴座上开取放窗口(当前值
   不触发)→ PCB 从前方套入
   4 根实心柱(柱顶直接承托 PCB)→ 从前方拧紧,螺母经前壁被拉紧
   (夹紧载荷路径:螺母 → 前壁 → 柱,全程受压)。螺钉规格 M4×12:
   夹持 PCB 1.6 + 柱 3 + 前壁 1.4 ≈ 6 mm + 螺母 3.4;备选
   `--attach tap` 自攻方案(柱内留 Ø3.4 底孔,背面直通到柱顶,直接
   自攻,免螺母);
3. **防滑**:底座底面有 6 个直径 `pad_d`(20 mm)、深 0.6 mm 的平底
   定位凹槽,1 mm 自粘 TPU 软垫装入后垫面高出底面约 0.4 mm——胶垫
   独占桌面接触(倾覆支点即垫接触线),也不吃裁切厚度公差;卡缘
   扣住垫边防蠕移,凹槽底整面可粘(中部一道 1 mm 减胶槽,垫直接
   跨过,不损失粘接面)。

## 嘉立创代打

- **上传 `.step`**(优先)或 `.stl`(`--step` 导出),都在 `out/` 里。
- **工艺建议**:首版验证件怎么便宜怎么来(FDM PETG/PLA);长期使用和
  将来的 v2 可调机构建议 PA12(MJF/SLS)——免支撑、强度好、耐蠕变,
  摩擦特性也适合铰链。
- **公差基准**(工艺未定,按两种工艺都稳妥取值):活动/配合面间隙
  ≥ 0.4 mm,壁厚 ≥ 1.6 mm,M4 螺母沉孔 7.4 mm 跨面 / 3.4 mm 深(已含
  余量)。确定工艺后可微调:FDM 再放宽约 0.1 mm,PA12 可收紧
  0.05–0.1 mm。
- **先打验证件**:`--part joint` 是两小块配合试块(榫键/榫槽、底面
  沉头、靴座螺母座),`--part fit` 是平板 + 全部柱位(1 组 × 4),都是
  几分钟打完:先用试块实测 0.4 mm 间隙是否顺手,再拿 PCB 和 M4 螺钉
  实配柱位与柱高,最后才下底座/立板的订单。

## 首版验证清单

1. 4 根 M4 柱与 PCB 对位(fit 件含全部柱位,试装螺钉与背面螺母:
   螺母压过收口唇且不回落);
2. `--post-h` 间隙:背面轴座/焊点/电池座不顶背板(背面若有 ~6 mm 高件

   面 ~2 mm 属正常,处在敞空处);
4. tilt=30°(默认)站姿:桌面实测后仰稳定性。默认**无配重**;实测不够再补偿,
   两个旋钮任选:加厚 `base_t`(6→12,+~120 g 最低位质量,键盘升高
   6 mm)、或调大 `base_rear`(重新出图);
5. 交界刚性:立板装上底座、从底面拧紧 2 颗 M4×12 后,按压背板顶部

6. 换装流程:松 2 颗螺丝换上另一角度立板(如 `--tilt 30`),确认榫键

## v2 路线:两件式已落地,单件内可调仍是后续

"背板 + 柱"独立于底座的两件式结构**已完成**(榫键 + 2×M4 螺丝,见
"两件式结构"一节):试不同倾角 = 打对应角度的立板件(`--tilt`),底座
通用。在此基础上的下一步才是**单件内连续可调**的摩擦铰链:M4/M5 枢轴

## 坐标换算

KiCad 的 Y 轴朝下,垂直站姿把板子旋转 90° 站起来;按"安装朝向"一节
的方向,两轴相对 KiCad 视图均翻转。换算不用手工常数,每次从 PCB 文件
推导(`stand.py` 的 `parse_pcb`):

- `u`(横向)= `Y_max − Y_kicad`
- `v`(离地高度,自小指加高键一侧板边)= `X_kicad − X_min`

`X_min` / `Y_max` 取自 Edge.Cuts **直边**端点(圆角弧的中点会外凸约
0.4 mm,不参与取框)。孔位换算结果与最后一次人工核对的孔位表
(`stand.py` 顶部的 `HOLES_EXPECTED`)逐项断言(±0.05 mm)。

除孔位外,`parse_pcb` 还把 Edge.Cuts 逐段(start/end 对;ergogen 已把
弧打散成短线)按 ~1 mm 步长插值成板框采样点,换算到同一站立系
返回——求解器高度约束的"PCB 最低点"取这些采样点逐角度旋转后的
最小值,不用包围盒角点(见"键盘离台高度"一节)。
