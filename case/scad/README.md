# C. Dux 垂直站立底座(OpenSCAD 版)

![preview](preview.png)

`stand.scad` 是垂直站立底座的 OpenSCAD 实现,**不需要 Python 环境**,装个
OpenSCAD 就能改参数、出 STL。同一设计的 Python/build123d 实现在
[`case/build123d/`](../build123d/),额外导出 STEP 供代打。

## 设计:垂直(dodo 式)站姿

面向**站立使用**:手臂自然垂下,手掌侧向,手指沿列方向卷曲按键。因此:

- **列竖直**、**控制器/拇指簇一侧朝下**(手指握拳时小指在上方、食指在下方,
  与 Dodo 等垂直键盘一致);
- 这个朝向同时把 MCU、电池座放到了**底部 → 重心低**,不容易后仰;
- USB 线在离底约 32 mm 高度从侧面引出,不会碰到背板和底座;
- 旋钮(encoder)位于中部高度、正对使用者,垂直放置时正好当音量键用;
- 裸板使用:PCB 由 4 根柱子架在背板前,`post_h`(默认 5 mm)保证背面
  的轴座/焊点/连接件不碰到背板;键帽朝向使用者一侧。

## 快速开始

```sh
# 导出整体 STL(默认 left half,tilt=20°)
openscad -o stand_full.stl case/scad/stand.scad

# 先打一个平板验证件:只有背板+4 根柱,几分钟就打完,
# 拿 PCB 比对 4 个 M4 孔位和 post_h 间隙
openscad -o stand_fit.stl -D 'part="fit"' case/scad/stand.scad

# 右半、垂直 0° 倾角
openscad -o stand_right.stl -D 'side="right"' -D 'tilt=0' case/scad/stand.scad
```

或者用 OpenSCAD GUI 打开 `stand.scad`,**Window → Customizer** 里拖滑块改参数,
F6 渲染后导出 STL。GUI 预览里可开 `show_pcb`(半透明 PCB + 红色 USB 标记)检查
孔位对齐;`%` 预览体不会导出到 STL。

## 打印建议

- 按建模姿态打印(底面朝下),**无需支撑**:背板只后仰 `tilt`(默认 20°),
  柱子和螺母沉孔都朝上敞开;底面两个硬币槽是 27 mm 桥接,普通切片器没问题。
- 0.2 mm 层高、3–4 层壁、10–15% gyroid 填充;PLA/PETG 均可(PETG 更耐蠕变)。
- 整件约 149 × 95 × 179 mm(tilt=20°),常见 220×220 成型尺寸打印机都能放。

## 装配

1. **固定 PCB**:4 × M4 螺钉(推荐 M4×10 内六角/圆头)+ M4 螺母。
   螺母放入柱顶六角沉孔 → PCB 从前方套入 4 根柱 → 拧紧,螺母被拉紧在沉孔里。
   备选:参数 `attach="tap"` 改为自攻方案(柱内留 M4 底孔,直接自攻,免螺母)。
2. **防滑**:底面有 6 个直径 `pad_d`(默认 20 mm)、深 0.8 mm 的定位凹槽,
   把自粘橡胶垫贴进凹槽即可,不易移位、不翘边。
3. **配重(可选)**:底座后侧面有两个 27 × 3.4 mm 硬币槽(约在 1 元硬币直径),
   每槽可叠 6 枚左右硬币(合计约 70 g),重力自锁,不掉出。
   后倾推力测试(粗算):整机 + 满配重后,在键盘顶部横向施加 ~100 gf 以上
   才会翘起,大于单键按压力量。若仍觉得不稳,加大 `base_rear` 或 `coin_slot` 加宽。

## 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `side` | `left` | 左/右半(镜像整体) |
| `part` | `full` | `fit` = 平板验证件 |
| `tilt` | 20 | 后仰角(度),0 = 完全垂直;照片实测站立舒适姿约 20–30° |
| `post_h` | 5 | 柱高 = PCB 与背板间隙;背面若有 JST 电池座等高件(约 6 mm)改成 7 |
| `attach` | `nut` | `nut` 螺母沉孔 / `tap` 自攻 |
| `base_rear` | 65 | 背板后方的底座深度,防后仰的主要配重臂(后仰角加大时保持稳定) |
| `pad_d` | 20 | 橡胶垫直径(凹槽随之变化) |
| `coin_slot` | `true` | 后侧硬币配重槽 |
| `label` | `"C.DUX"` | 底座正面浮雕文字,空串 = 不刻 |

## 坐标系(改孔位前必读)

KiCad 的 Y 轴朝下,而且垂直站姿是把板子**旋转 90°** 站起来的,所以
`holes` 里的 `[u, v]` 不是直接抄 KiCad 坐标,换算关系(已按
`ergogen/output/pcbs/c-dux.kicad_pcb` 左半算好,写在 `stand.scad` 头部注释):

- `u`(横向,自"顶行"长边)= `Y_kicad - 75.58`
- `v`(离地高度,自"控制器内侧边")= `154 - (X_kicad - 128.78)`

四个 M4 孔换算结果:

| 孔 | KiCad (X, Y) | stand `[u, v]` | 位置 |
|---|---|---|---|
| H1 | (256.66, 84.64) | `[ 9.06, 26.12]` | 底部(控制器侧) |
| H2 | (256.66, 146.54) | `[70.96, 26.12]` | 底部 |
| H3 | (158.07, 102.46) | `[26.88, 124.71]` | 上部(小指侧) |
| H4 | (178.80, 152.37) | `[76.79, 103.98]` | 上部 |

板框 154.0 × 112.5 mm;USB 出线点 `[18.26, 31.66]`(仅作预览标记)。

## 与 build123d 版(`case/build123d/`)的关系

同一垂直设计的两套实现,参数同名同默认:本版单文件、零 Python 依赖、
Customizer 拖滑块调参;[`case/build123d/`](../build123d/) 用 uv 管理,
导出 **STEP**(代打首选格式)并加了 B-rep 圆角,孔位/板框直接从
`pcb/v2.0/c-dux.kicad_pcb` 解析并内置断言。哪个顺手用哪个。

仓库,该方案已不存在。)
