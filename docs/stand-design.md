# stand.py 代码设计文档

面向**接手 `case/build123d/stand.py` 开发**的工程师。设计动机、装配流程、
公差体系、打印与代打指南在 [../case/build123d/README.md](../case/build123d/README.md),
本文不重复——本文回答"代码为什么长这样、改哪里要小心、怎么验证"。

## 1. 系统总览

```
pcb/v2.0/c-dux.kicad_pcb ──parse_pcb──┐
                                     ▼
                      Stand(pcb_w, pcb_h, holes, outline, …)
                       ├─ _solve_sets   柱位布局求解
                       ├─ _auto_ribs    肋位求解
                       └─ build(part) ──► STL/STEP ──► out/
```

- 单文件实现,依赖仅 build123d(0.11.1,uv 管理)+ 标准库;
- 输入是 KiCad PCB 文件(Ergogen 生成),**孔位/板框不手抄**;
- 输出按 `--part` 分:base(共享底座)/ upright(按角度立板)/
  full(装配预览)/ fit(平板验证件)/ joint(配合试块)/
  padtest(切片支撑试块,胶垫孔 + 沉头孔生产几何);
- 文件名:`stand_<side>_upright_t<tilt>_a<set-angles>[_flange<W>][_pads].stl`
  (fit 无 t 段;base 与 joint 试块不编码安装角;多个安装角用逗号连接)。
  **set-angles 编码在立板/装配预览文件名里**——同一 t30 下不同柱位旋转
  不会再撞名。
  注意 未镜像的建模体当前是右手件(随机选的,并无偏好):`--side left` 镜像
  立板/fit;full 预览中镜像立板沿 x 平移 2×band_mid 后与底座求并
  (复现真实装配)。

## 2. 三个坐标系(接手第一件事)

| 坐标系 | 定义 | 用在哪 |
|---|---|---|
| KiCad 系 | X 沿列方向(板高),Y 沿行方向(板宽);Y 朝下 | `parse_pcb` 输入 |
| 板局部系 | x 右、y 沿背板向上、z 朝前(柱子方向);背板厚 `plate_t`,轮廓 y ∈ [0, `plate_h`] | `plate_and_posts()` 全部几何 |
| 世界系 | 床面 = XY 平面,底座占 z ∈ [0, `base_t`],**用户在 −Y**;座面(接合面)z = `base_t` = 6 | 靴座/榫键/螺钉/法兰,以及导出的打印姿态 |

映射关系:

- KiCad → 站立系(安装朝向:小指加高键朝下、拇指簇朝上):
  `u = Y_max − Y_kicad`(横向)、`v = X_kicad − X_min`(离小指侧板边高度)。
- 站立系 → 板局部系(求解器输出):
  `x = u + shift − pcb_w/2`,
  `y = v + bottom_ext − keyboard_drop (+ lift)`(板底名义上比 PCB 底边
  低 `bottom_ext` = 6.5 mm,整组图案再沿板下移 `keyboard_drop` = 35.5 mm;
  lift 由高度约束解出,见 §5.1)。
- 板框采样:`parse_pcb` 除孔位外还返回 Edge.Cuts 实际轮廓的 ~1 mm
  采样点(站立系 (u, v);ergogen 已把弧打散成短线,端点 + 线性插值
  即可)。高度约束的"最低点"以这些采样点为准,不用包围盒角点——
  t30/−53 的真实最低点 (u,v) = (100.4, 31.6),比虚拟角点高 ~32 mm。
- 板局部系 → 世界系(`upright_solid` 的 `Pos(0,0,origin_z) * Rot(X=90−tilt)`):
  `y_w = st·y_l − ct·z_l`,`z_w = 6 + ct·y_l + st·z_l`
  (ct = cos tilt,st = sin tilt;`Rot(X=θ)` 右手系,z_w 随板内 y 以 ct
  增长——已用网格取点验证,与 `_solve_sets` 的 corner_z 公式同约定)。
  板顶向后仰 tilt,柱子垂直于板面。

## 3. 数据流与入口

`main()`(文件尾部):

1. 解析 `--side/--part/--tilt/--set-angles/--post-h/--attach/--flange/…`;
   校验:flange ∈ [0, 30],tilt/set-angles 非空;
2. `parse_pcb(args.pcb)` → `(pcb_w, pcb_h, holes, outline)`;
3. 每个 tilt 构造一个 `Stand`(base 只构造一次,与 tilt 无关);
4. `stand.build(part, side)`:未镜像体 = 右手件;left 侧 =
   `mirror(body, Plane.YZ)`(立板/fit;base 不镜像);full 预览中镜像
   立板沿 x 平移 2×band_mid 后与底座布尔并(复现真实装配);
5. `emit()`:导 STL,`--step` 加导 STEP,`--show` 只推送 OCP CAD
   Viewer(不导文件)。

## 5. 核心算法

### 5.1 `_solve_sets` — 柱位布局

输入每个安装组的平面内旋转角(`--set-angles`),输出 4 孔在板局部系的坐标:

1. 以 4 孔质心为中心旋转图案;
2. `v_floor`:旋转后板料允许到达的最低 v——保证板背面最低材料点沿板
   面下滑到底座顶的余量 ≥ `SLIDE_TOP_MARGIN`(1.5 mm,沿立板平面
   度量,等效世界竖直余量 = 1.5·cos tilt;唯一高度约束)。约束对象是
   Edge.Cuts 采样轮廓逐角度取 min,不是包围盒角点(右下角 bbox 角处
   无板料);
3. 每组在 ±`SHIFT_SPAN`(45)内按 `SHIFT_GRID`(3)步进暴力枚举横向平移,
   过滤:`|x| > PLATE_HALF_BOUND − 8`(64)或任意两柱距
   < `MIN_POST_CENTER`(11);
4. 评分字典序:max(最小柱距, 封顶 20)→ 组间跨度最小 → 偏移居中;
5. 无解 → 提示减少组数或减小角度。

高度/下移合成:`lift = max(0, v_floor − v'_min + keyboard_drop)`,柱位
`y = v' + bottom_ext − keyboard_drop + lift`——整组图案沿板下移
`keyboard_drop` 33 mm(实测需求 30,加高到 33 让约束绑定、进一步压低
立板),下移吃掉多少余量,
同一点料就需要多少额外抬升,净下移 = 33 − lift。最低孔位改自攻
底孔(`lowest_post_tapped`,H3 免螺母免沉孔)后,沉孔口
露出靴座顶面的旧操作限制消失,**真实板框高度底线成为唯一约束**,净
下移被它自动封顶:t30/−35 旧竖直 2 mm 约束时 lift ≈ 0.92,净下移 ≈
29.1 mm,最低点 z = 8.00(恰好绑定);t30/−45(drop 33)沿面 1.5 mm
约束绑定:lift ≈ 0.11,净下移 ≈ 32.9 mm,最低点 z = 7.30;当前默认
t30/−53(drop 35.5)同样绑定:lift ≈ 0,净下移 ≈ 35.5 mm,最低点
z = 7.31(沿面下滑余量恰 1.51,世界竖直 1.31);其它角度下高度
约束照常逐角度生效(沿面约束随 tilt 换算,低倾角等效竖直余量更大)。

当前默认 `TILT 30 / SET_ANGLES [-53]`:单组 4 柱,柱位 (x, y) =
H1 (61.7, 51.9) / H2 (24.5, 101.3) / H3 (−27.7, 6.8) /
H4 (−41.2, 59.1)(H3 最低、不打螺丝;t30/−53 下其 Ø15 喇叭口足环
越过板底缘 ~0.7 mm,由靴座前斜面——与板前脸共面——承载,四柱喇叭口
一致(flare_supported 自动校验;drop 30 时代曾整体落在板内);
靴座前伸埋唇之前该处只能删喇叭口打直壁 Ø10,且 y≥0 裁剪会切出
半喇叭残瘤(用户侧视渲染标出,已随埋唇废除));接合螺丝由靴座缘派生(靴座足迹 = 底带每侧内缩
`boot_inset` = 2,缘内缩 5.8,t30/−53 为 −46.2/+56.2,见 §5.2)后,
左侧没有靴座内有效肋位(H4 背面沉孔避让区与键条避让区把螺丝内侧
夹死,无缝隙),右侧全高肋 x = 44 + 左侧回退短肋 x = −34(h = 52,
见 §5.2);
原始底带(= 底座)x ∈ [−54, 64](+侧凸台承接外摆柱;带缘只
由柱位派生,见 §5.2/不变量 7);立板底带钳制到靴座足迹
x ∈ [−52, 62]、与靴座齐平(旧版底带在此每侧悬出靴座 2 mm,已废)。

### 5.2 `_auto_ribs` — 肋位

确定性布位:**每颗接合螺丝内侧一根肋**,中心 = 螺丝位向带中线内移
`nut_pocket_ac/2 + rib_t/2 + 1`(≈ 11.3),偶数 mm 取整——最外侧螺丝是
抗拉拔/夹紧锚点,其肋正对最大局部载荷,而螺丝外侧与靴座缘之间已无空间。
硬约束按序校验:

- 柱背面硬件:肋带(柱 y ∈ [−3, `rib_h`+6])内的柱横向避让 ≥12 mm
  (螺丝过孔/螺母沉孔出口不能被肋埋掉,与 `_cap_haunch` 同源的数字);
  初位撞柱时向带中线方向每次滑 2 mm 重试;
- 榫键条:键槽合并外缘(`band_mid ± (key_x + key_l/2 + joint_clear)`)
  两侧各留 ≥1 mm——肋必须待在所属螺丝那一侧,不许滑过键条;
- 靴座:整根肋缩进靴座缘 ≥1 mm(assert 保底;候选窗口即
  `boot_lo + 1 + rib_t/2 .. boot_hi − 1 − rib_t/2`)。

无位可落时回退**短肋**(用户要求保留左肋加强,不必与右肋对称):
x 取初位(螺丝位向带中线内移 ≈11.3、偶数取整;t30/−53 为 −34,
仍在键条内侧、不跨键条),高度自动下探——楔顶保持
在与其 x 跨度重叠的沉孔口下缘 ≥2 mm 之下(t30/−53:h = 52,由
H4 沉孔口下缘封顶;t30/−45 时代 h = 48)。注意封顶只看**靴座顶**
(背板背面高 8/ct ≈ 9.2)以上的柱:楔体在靴座带内没入靴座实体,
碰不到那里面的柱——H3 虽与短肋 x 跨度重叠,但其自攻通道在靴座带
内,不构成冲突(曾因把 H3 当沉孔柱而误算封顶 −0.7、把短肋丢掉,
已修)。净高 <25 或键条/靴座约束不过才放弃并打印 note(总根数
(含短肋)<2 打 warning)——布局拥挤的正常结果,不是 bug。肋不再加宽
靴座/底带(不变量 7);

### 5.3 `_taper_outline` — 收腰

底带以上(`y0 = rib_h/ct + taper_margin`)只保留“柱位包络凸包”:
柱心 ±(`post_d/2 + post_edge_margin`)的 keep-box 与段顶两角(即每侧
底带边缘,见不变量 7)做二维凸包。背板永不接触 PCB,所以肋带以上
只需要柱子和腹板。若 `y0 ≥ plate_h` 返回空(整板保留,不收腰)。
完全沉到 y0 以下的柱(H4 常态;t30/−53 的 H1 也在其列,keep-box 顶
61.9 < y0 82.8)不再被跳过,而是把 keep-box 的 x 跨度钳成 y0 上的一段
——否则凸包侧边会从顶柱 box 直连带缘角,这条弦在侧柱较低时会摆到
顶角切割线**内侧**,轮廓沿线→弦→线来回切换,在侧柱上方留下一级
台阶(t30/−40 用户渲染标出,红框);另在两条顶角线上各取 y0 高度
外側 2 mm 的锚点(钳到板料半宽),与顶柱 box 角(⊥ keep 10 > 线偏移
9.5)同在半平面外侧——半平面凸,故整条侧边恒在线外,每侧边界恒为
单一直线(t30/−35 逐位复现:体积 66.0017 cm³ 不变)。

**顶部两角直线切割**(`plate_and_posts`,按用户草图):收腰凸包之上,
顶部两角再用两条**单一直线**各切一刀——半平面 ∩ 板料的穿透厚切割
(`_half_plane_cutter`:对矩形做 Sutherland–Hodgman 半平面裁剪,与收腰
切割体同一 EPS 样式),切割后每条线的两个端点棱(屋脊尖 + 与板缘
交角,共 4 条板厚棱)倒 r3.5 圆角(用户要求手感;OCC 拒绝时半径
逐级回退 2.5/1.5,全败则打 warning 留尖角):

- 每条线 = 「顶柱 → 侧柱」线段向外整体平移 e = `post_d/2 + 4.5` =
  9.5 mm(喇叭口足环半径 7.5 + 外留 2 mm;首版 7 mm 会削去喇叭口
  外缘环台):边界从柱心外 9.5 mm 通过;外法向取线段垂线中背离靴座中心
  `(band_mid, y0)` 的那一支;
- 左线:顶柱(H2)→ 最左柱(H4);右线:顶柱(H2)→ 最右柱(H1)。
  每侧一条直通线,无多段切割;
- 两线间留下盖住顶柱凸台的顶帽(t30/−35 实测:凸台顶 y≈116.7 处
  帽宽 ≈10.0 mm,左缘 x≈7.2、右缘 x≈17.2;两线在 y≈121.1 相交、
  帽向上收尖,仍盖住整个凸台);
- 锚点全部取自柱位布局值,随布局改动自动跟随;
- **护栏**:每条线到每个柱心的垂直距离必须 ≥6.5 mm(螺母沉孔对角
  半径 4.16 + 壁余量,与托肩封顶 `_cap_haunch` 同值),
  不满足即 `sys.exit` 并列出全部距离——将来的布局改动必须在这里
  响亮失败,而不是悄悄削掉螺母沉孔(顶柱与两侧柱到本侧线恰为
  7.0 mm = 设计值,H3 很远);另 assert 锚点有限、顶柱凸台顶处
  顶帽 ≥8 mm(旧的 keep-box 锚定断言已废:边界现在刻意贴凸台外
  2 mm 通过,本就在旧 keep-box 余量之内,6.5 mm 柱心护栏是唯一
  防线;侧柱较低时两线可能在板顶 plate_h 之前闭合,故量凸台顶
  而非 plate_h)。`y0 ≥ plate_h`(无收腰)时整块跳过;
- 切割方向:`_half_plane_cutter` 切 a→b 左侧,按外法向与 a→b 左法向
  的点积自动翻转线方向,保证每侧都切在**外侧**(左线切左上、右线
  切右上,语义与旧版一致);两切面法向均朝上外,不新增悬空;
- `_half_plane_cutter` 曾用“取矩形投影最远的两角”闭合切割四边形:
  两个最远角落在矩形同一条边上时四边形折成凹镖形、悄悄少切(旧
  keep-box 锚定版的左线锚点正好触发),已改为对矩形做半平面裁剪,
  任意直线都得到准确的半平面 ∩ 矩形;
- t30/−53 实测(当前默认):左线 (19.35,109.30)→(−46.34,67.10)、
  右线 (32.08,107.03)→(69.33,57.59),凸台顶处帽宽 17.9 mm;两线与

## 6. 实体构造顺序(布尔管线)

### 6.1 `plate_and_posts`(板局部系)

1. `RectangleRounded(plate_w, plate_h, 8)` 拉伸 `plate_t`;
2. 减收腰切割体(段上方 − 凸包);
3. 每侧封边切割:按 `__init__` 派生的每侧底带边缘(不变量 7;钳制到
   靴座足迹后的带缘)切掉
   `over = plate_half − |band_edge|`;**`over ≈ 0` 时必须跳过**(零宽
   Box 会令 OCP 抛异常——3f09adf 修复的坑);有凸台侧走 45° 直线肩的
   多边形切割路径(两条直线取代旧 1/4 圆角肩;下肩交点 j = 2·柱心 −
   顶角切割线交点,使环下边缘余量与环顶越线量对称,并带 2 mm 环距
   保护,用户定稿);
4. 柱:`Cylinder(Ø10, post_h)`,底部 45° 喇叭口(`Ø15→Ø10` × 1.5,自
   支撑),四柱一致;足环越过板底缘的柱(下移后的最低柱)由靴座前
   斜面承载(与板前脸共面,见 §6.3.2);若足环越出靴座 x 跨度则回退
   直壁并打 note(`flare_supported`,兜底,当前布局不触发);柱顶实心,
   直接承托 PCB(Ø4.5 孔留 2.75 mm 径向壁)。曾有的 y ≥ 0 整体裁剪
   硬保底已删——它会把越缘喇叭口切成半喇叭残瘤,现由共面靴座替代;
5. 紧固孔位分两类。最低柱(H3)为**自攻底孔**(`lowest_post_tapped`):
   下移 30 后其背面沉孔会埋进靴座 z 区间无法放螺母,改为 Ø tap_d 底孔
(3.4 → 3.8 → 4.0:PETG 收缩 + 立式打印塌陷,用户实测逐次加大)
   供 M4 自攻螺丝直接拧入(免螺母免让位);孔在 `plate_and_posts`
   里先切、在靴座并集后**重切一次**(否则被靴座实体填掉),螺尾旋
   入靴座塑料反而增加咬合。其余 3 柱(`pocket_posts`)按 `--attach`:
   `nut`:背面六角螺母沉孔,
   开口在背板**背面**、径向完全落在 Ø10 柱足印内——六角沉孔(对边
   7.2 × 深 3.4 = 螺母 + 0.2 余量;背面直开无收口唇,旧 7.4 腔 + 6.9
   唇令螺母浮 0.2 mm/边、起牙费劲,已删——螺母轻推入位、夹紧前靠
   摩擦保持),留 2.6 mm 前壁由柱直接支撑,夹紧载荷路径 螺母 → 前壁 →
   柱(全程受压,无打印桥接受力)+ Ø4.5 螺丝通孔(背面直通到柱顶;
   穿过沉孔体积无妨,都是切割);螺钉 M4×12(夹持 PCB 1.6 + 柱 3 +
   壁 2.6 ≈ 7.2 mm + 螺母 3.2);`tap`:Ø4.0 自攻底孔,同样只打
   安装位、背面直通到柱顶(4 孔全自攻的备选)。

## 8. 不变量清单(改代码前必读)

1. **PCB 防呆**:`HOLES_EXPECTED` 断言永不绕过;PCB 改版后人工核对坐标
   (换算见 §2)再更新表;
2. **接合分工**:座面受压、榫键抗剪定位、2×M4 抗拉拔——挪键/螺钉前先
   重新推导;螺丝从底座底面向上拧(立板后仰后上方没有螺丝刀空间);
   **螺丝在最外侧 = 抗拉拔力臂最大;榫键以带中线居中 = 剪切路径居中**
   (不对称底带上两者都以 band_mid 锚定,随带自动跟随);
3. **免支撑**:任何几何改动后重跑 §8 的两个审计;新悬空面按"每层前移
   ≤ 半根线宽"原则处理(板底缘改由靴座前伸埋实就是这一规则的实例);
4. **可自由站立**:质心平面投影必须落在靴座足迹内、距后沿 ≥8 mm。
   已数据驱动:`__init__` 两遍构建自动后伸 `boot_rear`(t30/−53 实例
   后沿 34,实测质心 y 19.5,余量 14.5 mm;
   仍 ≥ 8;t30/−45 实例质心 y 20.6、余量 13.4);
5. **公差**:榫键/榫槽配合 0.2 mm(从 0.4 收紧,**先打 `--part joint`
   试块验证推入手感**);其余活动/配合面仍按各自设计值(螺钉通孔 4.5、
   螺母座 8.6);**切片端 X-Y 孔补偿保持
   0**,否则 7.2 mm 腔被补正缩到 < 螺母 7.0,螺母放不进;
6. **背板不接触 PCB**:`post_h` 是间隙;背板只升到最高柱顶 + `top_rim`;
7. **底座 = 原始底带齐宽;靴座 = 原始底带每侧内缩 `boot_inset`;
   立板底带 = 靴座足迹**(字面成立):每侧底带只由柱位派生——该侧
   最外柱 keep + 2 mm、偶数 mm 取整,受板料半宽与求解器横向包络
   (`PLATE_HALF_BOUND − 8`)封顶;柱位越界的一侧保持带在界上、走凸台
   (45° 直线肩)承接,不加宽整板;肋只在靴座内落位、不反向加宽;
   底座 slab 精确取原始底带足迹、靴座取每侧内缩 `boot_inset` 的足迹
   (非对称,以带中线为中心;内缩对称故 boot_mid == band_mid),立板
   底带钳制到靴座足迹、底部与靴座完全齐平——靴座完全坐在底座顶面
   2 mm 圆角内的平直区,底角无侧向悬出(t30/−53:底座 [−54, 64]、
   立板底带 = 靴座 [−52, 62])。旧“板底带每侧刻意悬出靴座 2 mm”与
   “已打印底座 132.5 是宽度基准”均已废除——用户已接受底座随本版重打
   (132.5 → ~114,接合螺丝孔位随后改为由靴座缘派生,见 §7/不变量 2);
8. 座面 z = 6 是唯一接合基准,所有连接特征用世界坐标定义、与倾角无关。

## 10. 已知限制与扩展点

- base 与 joint 试块的文件名不编码安装角:换角度重出时同名覆盖;底带
  随角度微移(1–2 mm 级),混用多组角度的底座/试块需自行区分;
- 柱位外摆时肋会被放弃(设计如此,脚本打 note/warning);接合螺丝由靴座
  缘派生,不再有“靴座盖不住螺丝位”的退出,只剩靴座宽不足以容纳两颗
  对角螺丝时的 assert(--set-angles 太散);
- 底座足迹非对称(跟随底带):`--part base` 按当前右布局坐标导出,
  左手布局需另行镜像(尚未参数化);
- 有效倾角范围 10–40°(受接合螺钉 y=14.5 落在靴座台上约束);
- 腹板减重孔已整体移除(历史见提交 b187149;站立姿态下孔顶是 ~Ø52 桥,
  牺牲的省料由收腰承担);
- `parse_pcb` 假设 Ergogen 导出的 KiCad 文本格式(gr_line Edge.Cuts、
  `ceoloide:mounting_hole_plated` 封装名);KiCad 版本变化导致格式变化时
  这里最先坏。
