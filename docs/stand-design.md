# stand.py 代码设计文档

面向**接手 `case/build123d/stand.py` 开发**的工程师。设计动机、装配流程、
公差体系、打印与代打指南在 [../case/build123d/README.md](../case/build123d/README.md),
本文不重复——本文回答"代码为什么长这样、改哪里要小心、怎么验证"。

## 1. 系统总览

```
pcb/v2.0/c-dux.kicad_pcb ──parse_pcb──┐
                                     ▼
                      Stand(pcb_w, pcb_h, holes, outline, …)
                       ├─ _solve_sets   柱位布局求解
                       ├─ _auto_ribs    肋位求解
                       └─ build(part) ──► STL/STEP ──► out/
```

- 单文件实现,依赖仅 build123d(0.11.1,uv 管理)+ 标准库;
- 输入是 KiCad PCB 文件(Ergogen 生成),**孔位/板框不手抄**;
- 输出按 `--part` 分:base(共享底座)/ upright(按角度立板)/
  full(装配预览)/ fit(平板验证件)/ joint(配合试块);
- 文件名:`stand_<side>_upright_t<tilt>[_flange<W>].stl`。
  注意 **stem 只编码 tilt 不编码 set-angles**——同一 t30 文件名可能对应
  不同柱位旋转,混用多组 `--set-angles` 时要另行区分(已知限制)。

## 2. 三个坐标系(接手第一件事)

| 坐标系 | 定义 | 用在哪 |
|---|---|---|
| KiCad 系 | X 沿列方向(板高),Y 沿行方向(板宽);Y 朝下 | `parse_pcb` 输入 |
| 板局部系 | x 右、y 沿背板向上、z 朝前(柱子方向);背板厚 `plate_t`,轮廓 y ∈ [0, `plate_h`] | `plate_and_posts()` 全部几何 |
| 世界系 | 床面 = XY 平面,底座占 z ∈ [0, `base_t`],**用户在 −Y**;座面(接合面)z = `base_t` = 6 | 靴座/榫键/螺钉/法兰,以及导出的打印姿态 |

映射关系:

- KiCad → 站立系(安装朝向:小指加高键朝下、拇指簇朝上):
  `u = Y_max − Y_kicad`(横向)、`v = X_kicad − X_min`(离小指侧板边高度)。
- 站立系 → 板局部系(求解器输出):
  `x = u + shift − pcb_w/2`,
  `y = v + bottom_ext − keyboard_drop (+ lift)`(板底名义上比 PCB 底边
  低 `bottom_ext` = 6.5 mm,整组图案再沿板下移 `keyboard_drop` = 20 mm;
  lift 由高度约束解出,见 §5.1)。
- 板框采样:`parse_pcb` 除孔位外还返回 Edge.Cuts 实际轮廓的 ~1 mm
  采样点(站立系 (u, v);ergogen 已把弧打散成短线,端点 + 线性插值
  即可)。高度约束的"最低点"以这些采样点为准,不用包围盒角点——
  t30/−35 的真实最低点 (u,v) = (76.7, 12.7),比虚拟角点高 ~31 mm。
- 板局部系 → 世界系(`upright_solid` 的 `Pos(0,0,origin_z) * Rot(X=90−tilt)`):
  `y_w = st·y_l − ct·z_l`,`z_w = 6 + ct·y_l + st·z_l`
  (ct = cos tilt,st = sin tilt;`Rot(X=θ)` 右手系,z_w 随板内 y 以 ct
  增长——已用网格取点验证,与 `_solve_sets` 的 corner_z 公式同约定)。
  板顶向后仰 tilt,柱子垂直于板面。

## 3. 数据流与入口

`main()`(文件尾部):

1. 解析 `--side/--part/--tilt/--set-angles/--post-h/--attach/--flange/…`;
   校验:flange ∈ [0, 30],tilt/set-angles 非空;
2. `parse_pcb(args.pcb)` → `(pcb_w, pcb_h, holes, outline)`;
3. 每个 tilt 构造一个 `Stand`(base 只构造一次,与 tilt 无关);
4. `stand.build(part, side)`:right 侧 = `mirror(body, Plane.YZ)`;
5. `emit()`:导 STL,`--step` 加导 STEP,`--show` 只推送 OCP CAD
   Viewer(不导文件)。

## 5. 核心算法

### 5.1 `_solve_sets` — 柱位布局

输入每个安装组的平面内旋转角(`--set-angles`),输出 4 孔在板局部系的坐标:

1. 以 4 孔质心为中心旋转图案;
2. `v_floor`:旋转后板料允许到达的最低 v——保证板背面最低材料点距底座
   顶面 ≥ `BASE_TOP_MARGIN`(2 mm,唯一高度约束)。约束对象是
   Edge.Cuts 采样轮廓逐角度取 min,不是包围盒角点(右下角 bbox 角处
   无板料);
3. 每组在 ±`SHIFT_SPAN`(45)内按 `SHIFT_GRID`(3)步进暴力枚举横向平移,
   过滤:`|x| > PLATE_HALF_BOUND − 8`(64)或任意两柱距
   < `MIN_POST_CENTER`(11);
4. 评分字典序:max(最小柱距, 封顶 20)→ 组间跨度最小 → 偏移居中;
5. 无解 → 提示减少组数或减小角度。

高度/下移合成:`lift = max(0, v_floor − v'_min + keyboard_drop)`,柱位
`y = v' + bottom_ext − keyboard_drop + lift`——整组图案沿板下移
`keyboard_drop` 30 mm(用户要求“键盘下移 3cm”),下移吃掉多少余量,
同一点料就需要多少额外抬升,净下移 = 30 − lift。最低柱不打螺丝
(`mount_lowest_screw = False`,H3 成纯承托柱、无沉孔)后,沉孔口
露出靴座顶面的旧操作限制消失,**真实板框高度底线成为唯一约束**,净
下移被它自动封顶:t30/−35 时 lift ≈ 0.92,净下移 ≈ 29.1 mm,最低点
z = 8.00(底座顶 6 + 2 mm 余量,恰好绑定);其它角度下高度约束照常
逐角度生效(如 `--set-angles -20` 时约束仍然 binds,最低点同样压在
8.0)。

当前默认 `TILT 30 / SET_ANGLES [-35]`:单组 4 柱,柱位 (x, y) =
H1 (62.8, 76.2) / H2 (12.1, 111.7) / H3 (−8.3, 5.6) /
H4 (−37.3, 51.2)(H3 最低、不打螺丝;喇叭口足环越出板底缘 ~1.9 mm,
由 §6.1 的 y ≥ 0 裁剪保底裁平——立板上实际由下前缘 45° 倒角先裁到
更深处);接合螺钉内移 ±35 后,左侧没有带内有效肋候选(H4 避让区
|x| ≤ −49.3 与带内下限 x ≥ −43 不相交),只解出右侧 1 根肋
(x = 57,脚本打 warning),底带 x ∈ [−50, 64](+侧凸台承接外摆柱;
带缘只由柱位派生,见 §5.2/不变量 7)。

### 5.2 `_auto_ribs` — 肋位

- 肋带:柱 y ∈ [−3, `rib_h`+6] 内的柱,横向避让 ≥12 mm(螺丝过孔在板背面
  出口不能被肋挡住);
- 避让榫键(|x| ≤ 12+15+`rib_t`/2+1)与接合螺钉(距 35 < 4.3+`rib_t`/2+1);
- 候选 x 必须**落在底带内**(每侧 |x| ≤ 带缘 −(`rib_t`/2+1))步进 2;
  从最右候选开始最远点采样,肋间距 ≥15;目标 `RIB_TARGET` = 5,
  **实际可能更少**(t30/−35 只放下 1 根;左侧候选空,直接不放,
  <3 会打印 warning)——布局拥挤的正常结果,不是 bug。肋不再加宽
  底带(不变量 7),并断言每根肋缩进带缘 ≥1 mm;

### 5.3 `_taper_outline` — 收腰

底带以上(`y0 = rib_h/ct + taper_margin`)只保留“柱位包络凸包”:
柱心 ±(`post_d/2 + post_edge_margin`)的 keep-box 与段顶两角(即每侧
底带边缘,见不变量 7)做二维凸包。背板永不接触 PCB,所以肋带以上
只需要柱子和腹板。若 `y0 ≥ plate_h` 返回空(整板保留,不收腰)。

**顶部两角直线切割**(`plate_and_posts`,按用户草图):收腰凸包之上,
顶部两角再用两条直线各切一刀——半平面 ∩ 板料的穿透厚切割
(`_half_plane_cutter`,与收腰切割体同一 EPS 样式),锐角不倒圆:

- 左线:(band_lo, y0+10) → (顶柱 x+5, plate_h+1),切去左上侧;
- 右线:(顶柱 x+12, plate_h+1) → (band_hi, 最外柱 y+11.7),切去右上侧;
- 两线间留下盖住顶柱的窄顶帽(锚点横向差 12−5 = 7 mm);
- 锚点全部取自布局值(带缘/柱位/plate_h),随布局改动自动跟随;
  建切割体前线条先向两端各外延 20 mm 再与板料边界相交,避免在板缘
  留 sliver 面;
- **护栏**:每条线到每个柱心的垂直距离必须 ≥6.5 mm(螺母沉孔对角
  半径 4.27 + 收口唇 + 壁余量,与托肩封顶 `_cap_haunch` 同值),
  不满足即 `sys.exit` 并列出全部距离——将来的布局改动必须在这里
  响亮失败,而不是悄悄削掉螺母沉孔;同时 assert 两条线的板上锚点
  都高于 y0(底带不可触及)。`y0 ≥ plate_h`(无收腰)时整块跳过;
- t30/−35 实测:最近距离左线→H2 7.73 mm、右线→H1 9.68 mm;
  立板 113 → 111 cm³,悬空/悬垂审计与 HEAD 持平(0.29 cm²、
  无孤岛,sub-45° 簇数不变),质心后移余量 9.8 → 10.1 mm。

## 6. 实体构造顺序(布尔管线)

### 6.1 `plate_and_posts`(板局部系)

1. `RectangleRounded(plate_w, plate_h, 8)` 拉伸 `plate_t`;
2. 减收腰切割体(段上方 − 凸包);
3. 每侧封边切割:按 `__init__` 派生的每侧底带边缘(不变量 7)切掉
   `over = plate_half − |band_edge|`;**`over ≈ 0` 时必须跳过**(零宽
   Box 会令 OCP 抛异常——3f09adf 修复的坑);有凸台侧走 1/4 圆角肩的
   多边形切割路径;
4. 柱:`Cylinder(Ø10, post_h)` + 底部 45° 喇叭口(`Ø15→Ø10` × 1.5,自
   支撑);柱顶实心,直接承托 PCB(Ø4.5 孔留 2.75 mm 径向壁);
5. **喇叭口裁剪**(y ≥ 0 半空间 ∩ 整块实体):下移大时最低柱的喇叭口
   足环会越出板底缘(t30/−35 drop 30:H3 柱心 y ≈ 5.6,足环到
   y ≈ −1.9)。板料本身都在 y ≥ 0,故柱并入后与一个宽裕的
   y ≥ 0 盒求交,越缘喇叭口被齐板底缘裁平(直立裁剪面,可打印;
   柱顶承托面不受影响)。立板的下前缘 45° 倒角在 t30/−35 裁得比它
   更深,实际由倒角收尾;此裁剪是 fit 件(无倒角)和其它倾角/布局
   的硬保底,t30/−35 实裁 ~0.01 cm³,量级可忽略;
6. `--attach nut`(只对**已安装柱** `mounted_posts`;最低柱按
   `mount_lowest_screw` 保持纯承托、无孔无沉孔):背面六角螺母沉孔,
   开口在背板**背面**、径向完全落在 Ø10 柱足印内——z 0..1.2 收口唇
   (对边 6.9,六角取向)、z 1.2..4.6 螺母位(对边 7.4 × 深 3.4);
   总深 4.6,留 1.4 mm 前壁由柱直接支撑,夹紧载荷路径 螺母 → 前壁 →
   柱(全程受压,无打印桥接受力)+ Ø4.5 螺丝通孔(背面直通到柱顶;
   穿过沉孔体积无妨,都是切割);螺钉 M4×12(夹持 PCB 1.6 + 柱 3 +
   壁 1.4 ≈ 6 mm + 螺母 3.4);`tap`:Ø3.4 自攻底孔,同样只打安装位、
   背面直通到柱顶。

### 6.2 `base_solid`(世界系)

底板**足迹精确取底带**(非对称:`bx` = `band_hi − band_lo`,Box 以带
中线为中心;旧固定宽 132.5 与 `base_side`/`upright_inset` 已废除——
靴座/底座/底带三者齐边,侧向零突出;布局改动移动底带时底座随版重打)
→ 竖直边圆角 10 → 顶面周边圆角 2 → 6 个胶垫凹槽(左右垫各自贴本侧
带缘:`band_edge ∓ (base_r + pad_edge)`;卡缘 + 全深平底,中部 1 mm
减胶槽把顶面拆成两个小桥;1 mm 胶垫高出底面 0.4)→ 并榫键 → 减
螺钉通孔与沉头孔(±`joint_screw_x`)。

### 6.3 `upright_solid`(世界系,顺序即打印姿态自上而下的层积)

1. `plate_and_posts()` 旋转到位;
2. **下前缘 45° 倒角**(`lip_chamfer`,锚在板座面角点 y=0):背板底缘面
   原本以 (90°−tilt) 掠过床面,是逐层前移的悬浮斜坡;倒角后每层前移
   ≤半根线宽。必须在靴座并集**之前**切;
3. 靴座 `Box(band_hi − band_lo, self.boot_rear − boot_front, 8)`(z 6..14;
   足迹**精确取底带**,与底座齐边——旧全宽靴座凸出带窄侧 ~14 mm 的
   侧突已废除;接合螺钉处螺母座外侧壁左 10.7 / 右 24.7 mm)。
   `boot_rear` 是**实例派生值**(模块常数 34 只是不下探的下限):
   `__init__` 先按硬下限(螺母座后壁 ≥1.5 mm、肋底 6 mm 后壁)建临时
   件,实测质心后把后沿伸到"质心投影距后沿 ≥8 mm",向上取偶数 mm
   重建一次——这是不变量 4 的落点,也是每条导出日志里 boot 行的来源;
4. 托肩楔(深 12,高度按 `_cap_haunch` 自动封顶 2–10,只数**已安装
   柱**的背面硬件)+ 肋楔(底深 `rib_t+8`=20、高 `rib_h`=70、
   厚 `rib_t`=12,位置来自 `_auto_ribs`)——都在靴座上、贴背板背面。
   (托肩 18→12、肋底 30→20:首版打印“底部偏臃肿”反馈后的收窄,
   强度按 4 层壁打印承担;托肩本就几乎全藏在靴座盒内,收窄不改体积,
   省料主要来自肋;最低柱不打螺丝后 t30/−35 无沉孔可顶,托肩回到
   全高 10 mm;左侧没有带内肋候选(H4 避让),只剩右肋 x = 57)
5. **最低“已安装”沉孔取放窗口**:某布局/下移把最低的**已安装**柱
   背面沉孔口埋进靴座 z 区间时(drop 20 时代的 t30/−35:沉孔口
   z 8.4..15.3 vs 靴座顶 14,螺母无法放入),在靴座上、与背板并集
   **之前**切一个 11 mm 宽的贯通窗口(y 到沉孔口后缘 + 螺母体 +
   2 mm;仅切靴座,背板沉孔与螺母座不动)。螺母经窗口放入,收口唇
   仍在背板内保持;最低柱不打螺丝后其沉孔不存在,窗口改盯最低
   **已安装**沉孔(t30/−35 drop 30:H4 沉孔口 z ≈ 47 ≫ 14,自动跳过);
6. `--flange` 时并上可掰法兰;
7. 减榫槽(贯穿)、螺母座;
8. 减 z<6 修剪盒(把低倾角下探到座面以下的柱喇叭口削平,底面落床)。

## 7. 常量分组

**调节旋钮**(改变造型/布局,改动后重跑审计即可):`plate_margin、
taper_margin、haunch_d、rib_*、RIB_TARGET、SHIFT_*、TILT、SET_ANGLES、
post_h(CLI)、flange_t、lip_chamfer、pad_*`。`keyboard_drop = 30` 特殊:
用户实测需求(“键盘下移 3cm”),整组安装图案沿板下移;净下移 =
30 − lift,由真实板框高度约束自动封顶在 ~29.1(2 mm 底座顶余量)。
曾用 20:当时最低柱背面沉孔口(含螺母摆动与 M4×12 尾部伸出的
~2.6 mm)必须露出靴座顶面,下移受此操作限制;`mount_lowest_screw =
False`(最低柱纯承托、无沉孔)后限制消失,30 直达底线。新布局若把
最低**已安装**沉孔埋进靴座,代码会自动开取放窗口(§6.3)。
`mount_lowest_screw` 特殊:False = 3 颗螺钉夹紧 + 最低柱纯承托——
敲击载荷是压向柱顶的单向力,4 柱全程受压;螺丝只抗拉拔,去掉最低
螺丝不改变受力方向,却解开了沉孔 vs 靴座对下移的限制。`bottom_ext = 6.5` 只是名义板底延伸:实际板底缘
= `bottom_ext − keyboard_drop + lift`,已基本贴住键盘最低材料点。
`boot_rear` 特殊:模块常数只是默认下限,实例值由 `__init__` 两遍构建
按质心自动后伸(见 §6.3),改它请改派生规则里的余量(8 mm)而不是常数。

**载荷/工艺设计值**(改前先读 README 对应章节,并与实物验证挂钩):
`joint_clear = 0.4`(FDM 公差基线)、`boot_nut_clear = 3.6`(抗蠕变承压)、
`nut_mouth_af = 6.9`(对螺母 7.0 的六角过盈收口,与沉孔同取向,靴座与
背面 PCB 沉孔共用同一 trick)、`nut_pocket_depth = 4.6` +
`nut_mouth_h = 1.2`(背面 PCB 螺母沉孔:唇 + 螺母位,留 1.4 mm 前壁由
柱直接支撑)、`post_d = 10`(实心柱,Ø4.5 孔留 2.75 mm 径向壁)+
`post_edge_margin = 5`(keep = 10,仍盖住 Ø8.6 螺母座 + 唇)、
`joint_screw_d = 4.5`(实印
基准)、`joint_screw_x = 35`(内移到收窄后的靴座上:±58 需要靴座
材料到 ±63.8,超出带缘不可能;±35 距键槽缘 ±27.4 有 3.3 mm 壁,
与肋自身的 11.3 mm 避让也不挤占带内柱位)、`MIN_POST_CENTER = 11`、`BASE_TOP_MARGIN = 2`、`key_h = 3.2 <
boot_nut_clear = 3.6`(立板承压落在座面而非键顶)、`base_t = 6`;胶垫

## 8. 不变量清单(改代码前必读)

1. **PCB 防呆**:`HOLES_EXPECTED` 断言永不绕过;PCB 改版后人工核对坐标
   (换算见 §2)再更新表;
2. **接合分工**:座面受压、榫键抗剪定位、2×M4 抗拉拔——挪键/螺钉前先
   重新推导;螺丝从底座底面向上拧(立板后仰后上方没有螺丝刀空间);
3. **免支撑**:任何几何改动后重跑 §8 的两个审计;新悬空面按"每层前移
   ≤ 半根线宽"原则处理(倒角锚点就是这一规则的实例);
4. **可自由站立**:质心平面投影必须落在靴座足迹内、距后沿 ≥8 mm。
   已数据驱动:`__init__` 两遍构建自动后伸 `boot_rear`(t30/−35 实例
   后沿 34,实测质心 y 22.8,余量 11.2 mm);
5. **公差基线 0.4 mm**:活动/配合面全部按此取;**切片端 X-Y 孔补偿保持
   0**,否则收口唇 6.9 > 螺母 7.0,常驻螺母失效;
6. **背板不接触 PCB**:`post_h` 是间隙;背板只升到最高柱顶 + `top_rim`;
7. **靴座 = 底座 = 底带,三者齐宽**(字面成立):每侧底带只由柱位派生
   ——该侧最外柱 keep + 2 mm、偶数 mm 取整,受板料半宽与求解器横向
   包络(`PLATE_HALF_BOUND − 8`)封顶;柱位越界的一侧保持带在界上、
   走凸台(quarter-round)承接,不加宽整板;肋只在带内落位、不再
   反向加宽带;底座 slab 与靴座精确取底带足迹(非对称,以带中线为
   中心)。旧“已打印底座 132.5 是宽度基准 + 立板每侧内缩 2 mm 避开
   顶面圆角”已废除——用户已接受底座随本版重打(132.5 → ~114,
   接合螺丝孔位 ±58 → ±35);
8. 座面 z = 6 是唯一接合基准,所有连接特征用世界坐标定义、与倾角无关。

## 9. 验证工具与流程

| 工具 | 输入 | 检查什么 |
|---|---|---|
| `overhang_report.py` | STL | 面级:按坡度分桶的下行面积 + <45° 连通簇定位(线宽无关) |
| `layer_float_audit.py` | STL | 层级:0.2 mm 逐层切片差分,真实悬空面积/最差层/"空中起印"孤岛(真失败风险) |
| `--part joint` | — | 榫键/榫槽/螺母座实物配合,任何几何改动后先打 |

两者都以导出姿态(STL 即打印姿态)、0.2 mm 层、~0.25 mm 支撑带宽为假设。

**当前基线**(t30/−35 左立板,drop 30 + 3 螺钉 + 1 承托柱后):悬空合计
0.24 cm²(合 0.00 cm³),最差单层
1.6 mm²(顶柱喇叭口腹线,z ≈ 106),无孤岛;质心 (7.8, 22.5, 41.5)。
回归时数字应同量级。

```sh
uv run --with trimesh --with shapely --with numpy --with networkx \
  --with rtree python layer_float_audit.py out/stand_left_upright_t30.stl
uv run --with numpy python overhang_report.py out/stand_left_upright_t30.stl
```

## 10. 已知限制与扩展点

- stem 不编码 set-angles(§1);多角度组合并存时需自行区分;
- 柱位外摆时肋会少于 `RIB_TARGET`(设计如此);底带盖不住
  ±(`joint_screw_x` + 螺母座半径 + 1)时直接退出(--set-angles 太散);
- 底座足迹非对称(跟随底带):`--part base` 按当前左布局坐标导出,
  右手布局需另行镜像(尚未参数化);
- 有效倾角范围 10–40°(受接合螺钉 y=14.5 落在靴座台上约束);
- 腹板减重孔已整体移除(历史见提交 b187149;站立姿态下孔顶是 ~Ø52 桥,
  牺牲的省料由收腰承担);
- `parse_pcb` 假设 Ergogen 导出的 KiCad 文本格式(gr_line Edge.Cuts、
  `ceoloide:mounting_hole_plated` 封装名);KiCad 版本变化导致格式变化时
  这里最先坏。
